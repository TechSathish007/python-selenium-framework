# Enterprise Python Selenium Framework 🚀

A professional-grade UI automation framework built from scratch to demonstrate advanced testing capabilities. 

## 🏗️ Architecture & Tech Stack
* **Language:** Python 3
* **Automation Engine:** Selenium WebDriver
* **Test Runner:** Pytest
* **Design Pattern:** Page Object Model (POM)
* **Reporting:** Allure Reports
* **CI/CD:** GitHub Actions

## 🌟 Advanced Features Implemented
1. **Cross-Browser Testing:** Supports Chrome, Firefox, and Edge via custom CLI commands (`--browser=edge`).
2. **Data-Driven Testing:** Automatically parses external `.csv` files to loop through multiple data sets.
3. **Smart Waiting Strategies:** Utilizes Selenium `WebDriverWait` (Explicit Waits) to ensure 100% test stability without hardcoded sleeps.
4. **Complex Web Elements:** Successfully handles tricky DOM elements like JavaScript Alerts and dynamic Drop-down Menus.
5. **Headless Execution:** Fully configured for silent, background execution.
6. **Continuous Integration:** Automated cloud pipeline triggers test execution on every repository push.
